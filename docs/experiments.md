## 四、读这些结论前必须知道的三件事

按重要性排：

1. **生存者偏差污染的不只是策略，还有基准和择时信号。**
   等权持有 +16.84% → +11.50%，择时同参数夏普 0.75 → 0.63。
   **跨脚本引用任何绝对百分比之前，先确认两边同口径。**（`17_survivorship.py`）

2. **模型测试段只有 388 天，相位噪声可达 142 个百分点年化。**
   小于约 100 个百分点的差异读不出统计意义。凡是标着「k=3 交叉臂」的都受这条
   约束。`23_oos_window.py` 的 `mid` 分段能把它降到约 49。

3. **Rank IC 在 k=3 上是差代理。** 反复出现：5 日反转 Rank IC 高于模型而收益只有
   1/20；扩池后 Rank IC 只掉 16% 而 top-3 塌了三分之二。它度量全截面排序，
   而 top-3 只用到最顶端三个位置。
