# P3 模型与选股验证记录

验证日期：2026-08-10。数据为本地 parquet 缓存中的当前沪深300成分，训练区间
2020–2023、验证区间 2024、测试区间 2025–2026-08-10。标签为未来两个开盘价
之间的收益 `Ref($open,-2)/Ref($open,-1)-1`。

## 多 seed IC

**2026-08-10 复权因子修复后重训**（股票池同时由 290 扩到 299）：

| seed | Rank IC（修复后） | Rank IC（修复前） |
|---:|---:|---:|
| 42 | +0.040568 | +0.042082 |
| 43 | +0.040147 | +0.041810 |
| 44 | +0.042109 | +0.041844 |
| 三 seed 集成 | **+0.041358** | +0.042343 |

修复后集成 Rank IC 下降 `-0.000985`。**这个差异小于 seed 之间的离散度**
（修复后三 seed 跨度 0.040147~0.042109，即 0.00196），所以不能说"修复让模型
变差了"——只能说修复后的数字是**在正确数据上测出来的**，因此是应当采信的
那一个。

三个 seed 方向一致且均大于 0，仍满足 P3 验收。训练产物保存
`seed_predictions.pkl` 和 `seed_rank_ic.pkl`，便于以后复查，而不只保存平均值。

> 修复前的训练集里含有伪造的复权收益，最严重的是平安银行 2020-12-31 的
> 假阴线（原始 +0.73%，复权后 −16.21%）。详见 `docs/data-sources.md`。

## 行业中性化对照

### ⚠️ 结论已翻转，`QBG_INDUSTRY_NEUTRAL=1` 需要重新决策

**2026-08-10 复权因子修复 + 重训后**（同一份三 seed 预测、top-3、
基础往返成本 10.2bp、股票池 299 只）：

| 指标 | 原始分数 | 申万一级行业内 demean |
|---|---:|---:|
| 年化收益 | **+36.37%** | +28.82% |
| Sharpe | **1.37** | 1.14 |
| 最大回撤 | **-23.47%** | -24.24% |
| 平均换手/期 | **0.193** | 0.196 |
| Rank IC | **+0.0415** | +0.0210 |

**中性化在每一项上都更差**，和下面这份旧结论完全相反：

| 指标 | 原始分数 | 行业内 demean |
|---|---:|---:|
| 年化收益 | 30.78% | **31.43%** |
| Sharpe | 1.174 | **1.190** |
| 最大回撤 | -30.01% | -30.31% |
| 平均换手/期 | 0.196 | **0.191** |

当时据此保留 `QBG_INDUSTRY_NEUTRAL=1`。
</details>

**不能把翻转归因于任何单一原因。** 这次同时变了三样东西：

1. 复权因子修复（4 只股票的历史收益被改正）
2. 股票池 290 → 299
3. 重训（seed 之间本身就有 ±0.001 的 Rank IC 摆动）

已排除的可能：行业分类表**没有**损坏——299/299 全部有申万一级归属，
26 个行业组，只有「美容护理」1 个单成员组（demean 后恒为 0）。

Rank IC 减半（0.0415 → 0.0210）本身不算异常：中性化就是**故意丢掉行业层面的
信号**，截面 Rank IC 必然下降。真正的问题是组合层面的收益/Sharpe 也一起变差，
而旧结论说它们会变好。

**建议**：在把 `QBG_INDUSTRY_NEUTRAL` 改成 0 之前，走 `tuning/` 的八项回测闸
做一次受控评估（固定股票池和 seed，只切换中性化开关，并检查子区间稳定性）。
本次只有单点观测，不足以翻一个已部署的参数。

滑点敏感性（修复后、原始分数）：+10bp 年化 +24.21%，+20bp +13.06%，
+30bp +2.90%。执行成本和低换手仍是关键。

## 不能据此得出的结论

这些数字存在显著生存者偏差：当前成分股回看历史会只保留活到今天的公司；模型
回测还没有模拟手工下单延迟。它们足以验收代码和信号方向，不应直接当作未来收益
预期。积累带日期的股票池快照后必须重跑。
