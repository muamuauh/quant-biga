## 行业中性化对照

同一份三 seed 预测、top-3、基础往返成本 10.2bp：

| 指标 | 原始分数 | 申万一级行业内 demean |
|---|---:|---:|
| 年化收益 | 30.78% | **31.43%** |
| Sharpe | 1.174 | **1.190** |
| 最大回撤 | -30.01% | -30.31% |
| 平均换手/期 | 0.196 | **0.191** |

中性化略微提高收益/Sharpe 并降低换手，代价是最大回撤恶化 0.30 个百分点；保留
`QBG_INDUSTRY_NEUTRAL=1`。20bp 额外滑点下年化仍为 +9.16%，30bp 时接近归零，
再次说明执行成本和低换手是关键。

## 不能据此得出的结论

这些数字存在显著生存者偏差：当前成分股回看历史会只保留活到今天的公司；模型
回测还没有模拟手工下单延迟。它们足以验收代码和信号方向，不应直接当作未来收益
预期。积累带日期的股票池快照后必须重跑。
